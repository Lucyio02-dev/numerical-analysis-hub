## 这是什么

数值分析（计算方法）是一门「公式多、证明密、计算繁」的课。只看讲义容易陷入两个困境：**看不到误差是怎么放大的**、**记不住公式该在什么场景用**。

这个页面把 11 章内容重新组织成「可操作」的学习路径：

- 先用**章节依赖图**看清哪章是前置、哪章是枢纽；
- 每章给出要点清单 + 核心公式 + 易错点；
- 关键概念配一个**能拖参数的实验**，让抽象的误差、收敛、振荡直接出现在眼前；
- 最后用**考前锦囊**（10 条证明链条 + 10 个计算标准动作）和 **10 道概念自测**收束。

配套教材：郑慧娆等《数值计算方法》。

## 14 个互动实验

| 编号 | 实验 | 想让你看到什么 |
| --- | --- | --- |
| 1A | IEEE 754 浮点数拆解器 | 符号位 / 指数位 / 尾数位如何拼出一个数，十进制有限小数为何存不准 |
| 1B | 灾难性抵消 | 数学恒等的两种算式，数值误差可以差出十几个数量级 |
| 2A | p-范数单位球 | 换一种范数，「单位圆」就不再是圆 |
| 2B | 条件数 = 误差放大器 | κ 每翻 10 倍，解就少一位可信数字 |
| 3 | Gauss 消元步进机 | 3×3 方程组逐格消元，看清乘数如何拼成 L、上三角如何成为 U |
| 4A | Jacobi vs Gauss-Seidel | 同一初值下两条收敛路径的差异 |
| 4B | SOR 松弛因子 | ρ(ω) 曲线上先缓后陡的「悬崖」，ω≥2 必发散 |
| 5 | 求根方法赛跑 | 二分 / Newton / 弦截同场对比，误差列指数直接显示收敛阶 |
| 6 | 最小二乘拟合沙盘 | 画布上点数据、调次数，看高阶拟合如何过拟合、法方程条件数如何爆炸 |
| 7 | 幂法实况 | 迭代向量如何「转向」主特征方向，λ₂/λ₁ 接近 1 时为何失效 |
| 8 | Runge 现象 | 等距节点加密反而端点振荡，切到 Chebyshev 节点误差被压平 |
| 9 | Chebyshev 多项式解剖 | 等幅振荡为何是最优一致逼近，节点乘积如何把误差摊平 |
| 10 | 复化求积 + Romberg 外推 | 双对数误差曲线的斜率就是收敛阶，外推表逐列逼近精确值 |
| 11 | ODE 稳定性实验场 | 拖动 z = λh 越过红线，Euler / 改进 Euler / RK4 逐个振荡发散 |

## 技术栈

- **纯静态**：HTML + CSS + 原生 JavaScript，无框架、无构建步骤、无包管理器依赖
- **绘图**：Canvas 2D 手写坐标映射与曲线绘制，跟随主题色重绘
- **公式排版**：MathJax 3.2.2（`tex-svg`），本地自托管 + 多 CDN 兜底
- **图表**：课程依赖图为手写 SVG，含箭头 marker 与主线高亮样式
- **存储**：`localStorage` 保存章节完成状态

## 本地运行

方式一：直接双击 `index.html`，浏览器打开即可（推荐 Chrome / Edge / Firefox / Safari 新版本）。

方式二：起一个本地静态服务器（避免个别浏览器对 `file://` 的限制）：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

### 关于公式渲染

页面通过 MathJax 将 `$...$` 渲染为公式。加载顺序为：

1. 本地 `vendor/mathjax/tex-svg.js`（优先，离线可用）
2. jsDelivr → npmmirror → unpkg → cdnjs（依次兜底）

因此 **拷贝或部署时请连同 `vendor/` 目录一起带走**；若只保留 `index.html`，将回退到 CDN，弱网或受限网络下公式可能显示为源码。

## 部署到 GitHub Pages

本仓库根目录即站点根目录，无需构建：

1. 仓库 **Settings → Pages**
2. Source 选择 `Deploy from a branch`，分支 `main`、目录 `/ (root)`
3. 保存后等待约 1 分钟，访问 `https://<用户名>.github.io/numerical-analysis-hub/`
